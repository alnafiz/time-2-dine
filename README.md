# 🍽️ Time2Dine (v1.0 - Legacy Prototype)

> **Archival Note:** This repository contains the initial, legacy prototype of **Time2Dine**, developed during my 2nd year for an undergraduate Web Development course. A complete **v2.0 rebuild** featuring modern web frameworks and AI-assisted workflows will be launched in a separate repository.

---

## 📌 About the Project

**Time2Dine** is a third-party restaurant reservation and smart table management web application. It bridges the gap between food lovers and top-tier dining spots across the city, making dining out completely seamless and hassle-free. 

Instead of manual phone calls or chaotic queues, Time2Dine allows users to discover restaurants, view menus, and reserve tables dynamically based on party size.

---

## ✨ Key Features

* 🪑 **Automated Table Recommendation:** Smart dynamic table allocation system that suggests the most suitable seating arrangements based on the number of guests entered by the user.
* 🏬 **Multi-Restaurant Listing:** A curated platform featuring popular restaurants, cafes, and bakeries.
* 🔍 **Smart Restaurant Search:** Easily search for dining spots by cuisine type, restaurant name, or location.
* 📜 **Individual Restaurant Pages:** Dedicated landing pages for partner restaurants with custom reservation flows and menus.
* 📱 **Responsive Frontend:** Integrated with Swiper.js and custom CSS for smooth sliders and layout responsiveness across devices.
* 📩 **Direct Contact & Inquiry Form:** Built-in form for customer feedback, partner inquiries, and support.
